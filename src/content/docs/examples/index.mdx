Each example solves one common game task with complete scripts you can paste into a project:
what it does, how to set the scene up in the editor, the code, what each part does, and changes
to try. Every code block on these pages is compiled against the engine when the site is built.

Most of them come from the editor's demo project (`examples/demo_project`, opened the first time
the editor starts): "Legacy of the Wardens", a platformer with menus, options, dialogue, three
LDtk levels and a boss. Its README says where each feature is used. If you haven't written a script
yet, start with [Your first game](/getting-started/first-game/), then [Scripts](/manual/scripts/)
in the manual.

<Aside type="note">
Scripts use constants from your project's generated `scripts/assets.odin` (`SOUND_COIN`,
`ACTION_JUMP`...). Each page shows the lines it needs; your project has them once you've imported
the files and added the input actions. Don't copy that block into your project: the editor writes
the file.
</Aside>
